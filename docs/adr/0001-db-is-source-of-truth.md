# 単語データの正は DB に置き、スプレッドシートは入力元にする

単語の元データは Google スプレッドシート（章と汉语のみ）にあるが、ピンインと意味は Claude が補い、学習のステータスも持つため、Supabase の DB を正とする。シートは公開リンクで読み取り専用のため書き戻せず、書き戻しや同期を作ると複雑になる。新しい単語は、シートに追記して Claude に依頼し、追加用 SQL を DB で実行して足す（既存の単語は上書きしない）。

単語データは公開リポジトリに入れない。リポジトリにはテーブル定義とセキュリティ設定の SQL だけを置き、単語の SQL は `.gitignore` で除外してローカルにだけ置く。

## Considered Options

- **シートを正にして実行時に読む**: 更新は楽だが、ピンイン・意味・ステータスの置き場がなく、読み取り専用の公開リンクには書けない。
- **シートへ双方向同期**: 書き込みに認証が必要になり、1人用アプリには過剰。
